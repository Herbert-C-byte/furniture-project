# **📌 Furniture Project**  
*A modern, responsive furniture showcase website*  
 

## **✨ Features**  
✅ **Responsive Design** – Works on mobile, tablet, and desktop  
✅ **Interactive UI** – Smooth animations and transitions  
✅ **Product Catalog** – Displays furniture items with details  
✅ **Filter & Search** – Easily find products by category  

## **🚀 Quick Start**  
1. **Clone the repo**  
   ```bash
   git clone https://github.com/Herbert-C-byte/furniture-project.git
   ```
2. **Install dependencies**  
   ```bash
   npm install  # or `yarn install` if using Yarn
   ```
3. **Run the project**  
   ```bash
   npm start
   ```
4. **Open in browser**  
   ```
   http://localhost:3000
   ```

## **🛠 Technologies Used**  
- **Frontend:** HTML5, CSS3, JavaScript (React/Vanilla JS)  
- **Styling:** Tailwind CSS / Bootstrap *(adjust based on what you use)*
